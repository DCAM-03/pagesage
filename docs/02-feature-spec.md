# PageSage 功能规格文档

版本：0.1  
日期：2026-06-13  
状态：详细功能规格  

## 1. 功能优先级

| 优先级 | 含义 |
| --- | --- |
| P0 | MVP 必须实现，否则产品无法形成基础闭环 |
| P1 | Alpha/Beta 必须实现，是完整阅读器体验的关键 |
| P2 | v1.0 或后续增强 |
| P3 | 长期探索 |

## 2. 书库

优先级：P0

### 2.1 功能说明

书库是 PageSage 的主入口，用于展示、筛选、排序、打开和管理所有已导入书籍。

### 2.2 入口

- 应用启动默认进入书库。
- 底部导航的“书库”。
- 桌面左侧栏的“书库”。

### 2.3 页面内容

书库页面包含：

- 顶部搜索框。
- 导入按钮。
- 扫描文件夹按钮，P2。
- 视图切换：
  - 网格
  - 列表
  - 紧凑列表
- 排序菜单。
- 筛选菜单。
- 分类入口。
- 书籍列表或空状态。

### 2.4 书籍卡片

网格卡片显示：

- 封面。
- 标题。
- 作者。
- 阅读进度条。
- 格式角标。
- 最近阅读时间，悬浮或详情中显示。

列表项显示：

- 小封面。
- 标题。
- 作者。
- 分类。
- 标签。
- 格式。
- 阅读进度。
- 最近打开时间。

### 2.5 操作

单击或点击：

- 打开书籍。

长按或右键：

- 继续阅读。
- 详情。
- 重命名展示标题。
- 修改作者。
- 移动到分类。
- 添加标签。
- 收藏。
- 标记已读。
- 重建索引。
- 重新提取封面。
- 从书库移除。
- 删除应用副本和数据。

### 2.6 状态

| 状态 | 表现 |
| --- | --- |
| 空书库 | 展示空状态插画、导入按钮、扫描文件夹按钮 |
| 加载中 | 展示骨架屏 |
| 有书籍 | 展示书籍列表 |
| 导入中 | 书籍可预占位，显示导入进度 |
| 索引中 | 卡片显示轻量状态，不阻塞打开 |
| 错误 | 顶部或卡片展示可恢复错误 |

### 2.7 验收标准

- 用户能看到所有已导入书籍。
- 重启应用后书库仍存在。
- 排序和筛选结果正确。
- 书籍卡片能正确展示进度和格式。
- 删除操作不会误删原始路径文件，除非用户明确选择。

## 3. 导入

优先级：P0

### 3.1 支持格式

- `.epub`
- `.pdf`

暂不支持：

- `.mobi`
- `.azw`
- `.azw3`

### 3.2 入口

- 书库顶部导入按钮。
- 空书库主按钮。
- 桌面端拖拽文件到窗口，P2。

### 3.3 导入 EPUB/PDF 流程

1. 用户选择文件。
2. 应用计算文件 hash。
3. 检查是否重复。
4. 复制文件到应用书库目录。
5. 写入 books 表。
6. 提取元数据和封面。
7. 创建全文索引任务。
8. 刷新书库。

### 3.4 暂不支持格式

用户选择 MOBI/AZW/AZW3 或其他未支持格式时：

1. 不创建 book 记录。
2. 不创建转换任务。
3. 显示“当前版本暂不支持此格式”。
4. 可提示用户先转换为 EPUB 后再导入，但不提供 Calibre 路径设置或自动检测。

### 3.5 异常

| 场景 | 处理 |
| --- | --- |
| 文件不存在 | 提示文件不可访问 |
| 文件无权限 | 提示授权或复制到可访问目录 |
| 重复导入 | 提示打开已有书籍、导入副本、取消 |
| 文件损坏 | 提示导入失败并保留日志 |
| 格式暂不支持 | 提示当前版本支持 EPUB/PDF |
| 磁盘空间不足 | 提示清理空间 |

### 3.6 验收标准

- EPUB/PDF 可以导入并出现在书库。
- 重复文件能被识别。
- 导入失败不会留下无效书籍记录。
- 选择暂不支持格式时不会创建无效任务或书籍。

## 4. EPUB 阅读

优先级：P0

### 4.1 功能说明

EPUB 阅读器提供可重排文本阅读体验，支持目录、翻页、样式调整、搜索、书签、划线和 AI。

### 4.2 MVP 功能

- 打开 EPUB。
- 恢复上次位置。
- 翻页或滚动。
- 字号调整。
- 背景调整。
- 亮色/夜间主题。
- 保存阅读进度。

### 4.3 Alpha 功能

- 目录跳转。
- 书内搜索。
- 书签。
- 划线。
- 笔记。
- 阅读模式：
  - 分页
  - 连续滚动

### 4.4 Beta 功能

- 划词 AI。
- 当前章节总结。
- AI 回答保存为笔记。

### 4.5 设置项

- 字号。
- 字体。
- 行高。
- 段落间距。
- 页边距。
- 背景色。
- 文字色。
- 链接色。
- 阅读模式。
- 翻页动画，P2。

### 4.6 定位规则

主定位：

- EPUB CFI。
- 分页模式下的 href + chapter index + chapter offset。

备用定位：

- spine item href。
- chapter index。
- percentage。
- selected text excerpt。

### 4.7 验收标准

- 关闭应用后能恢复到上次阅读位置。
- 修改字号后当前书籍不丢失位置。
- 目录项点击后能跳转。
- 无网络状态下可阅读已导入 EPUB。

## 5. PDF 阅读

优先级：P0

### 5.1 功能说明

PDF 阅读器提供固定版式阅读，支持页码、缩放、搜索、书签、笔记和 AI。

### 5.2 MVP 功能

- 打开 PDF。
- 恢复页码和滚动位置。
- 连续滚动。
- 页码显示。
- 缩放。
- 适合宽度。

### 5.3 Alpha 功能

- 页码跳转。
- PDF outline。
- 书内搜索。
- 书签。
- 文本选择。
- 笔记。

### 5.4 Beta 功能

- 划词 AI。
- 单页总结。
- 选区保存为笔记。

### 5.5 阅读模式

- 连续滚动，默认。
- 单页。
- 双页，桌面和平板。
- 适合宽度。
- 适合页面。

### 5.6 定位规则

主定位：

- page number。
- scroll offset。
- zoom。

增强定位：

- text excerpt。
- selection rectangle，后续。

### 5.7 异常

| 场景 | 处理 |
| --- | --- |
| 加密 PDF | 提示输入密码，P2 |
| 扫描版 PDF | 可阅读，但提示无法全文搜索 |
| PDF 损坏 | 显示打开失败 |
| 文本层缺失 | 禁用划词相关能力 |

### 5.8 验收标准

- PDF 能打开并滚动。
- 退出后能恢复到对应页。
- 缩放后页面不出现明显错位。
- 搜索不可用时原因明确。

## 6. 分类与标签

优先级：P1

### 6.1 分类

分类是目录树结构。一本书只能有一个主分类。

默认分类：

- 全部书籍。
- 最近阅读。
- 收藏。
- 未分类。
- 已读。

操作：

- 新建分类。
- 新建子分类。
- 重命名。
- 删除。
- 移动书籍。
- 调整排序。

删除分类规则：

- 删除分类不删除书籍。
- 被删除分类下的书籍移入未分类，或由用户选择目标分类。

### 6.2 标签

标签是多对多结构。一本书可以有多个标签。

操作：

- 新建标签。
- 设置标签颜色。
- 给书籍添加标签。
- 移除标签。
- 按标签筛选。

### 6.3 验收标准

- 分类树重启后保持。
- 一本书移动分类后立刻反映到书库。
- 标签筛选结果正确。

## 7. 书签

优先级：P1

### 7.1 功能说明

书签用于保存书内位置，可以带简短备注。

### 7.2 入口

- 阅读器工具栏书签按钮。
- 阅读器右侧书签面板。
- 全局笔记/书签入口。

### 7.3 操作

- 添加当前页或当前位置书签。
- 取消当前书签。
- 编辑备注。
- 删除书签。
- 从书签跳转原文。
- 搜索书签备注。

### 7.4 验收标准

- 添加书签后工具栏状态更新。
- 书签能跳回原文位置。
- 删除书签不影响笔记。

## 8. 划线与笔记

优先级：P1

### 8.1 划线

支持样式：

- 黄色高亮。
- 蓝色高亮。
- 绿色高亮。
- 红色重点。
- 下划线。

操作：

- 选中文本后高亮。
- 修改高亮颜色。
- 删除高亮。
- 从高亮创建笔记。

### 8.2 笔记

笔记类型：

- 文字笔记。
- 摘录笔记。
- AI 回答笔记。
- 问题卡片。

笔记字段：

- 标题。
- 内容。
- 来源书籍。
- 原文。
- 定位。
- 标签。
- 创建时间。
- 更新时间。

### 8.3 笔记页面

功能：

- 按书籍筛选。
- 按标签筛选。
- 按时间排序。
- 搜索笔记。
- 编辑笔记。
- 删除笔记。
- 跳转原文。

### 8.4 Notebook

阅读器内将书签、划线、笔记和当前书籍 AI 历史集中为 Notebook 侧栏或底部抽屉。条目支持按书内位置浏览、跳回原文、复制内容，并对书签、标注、笔记执行对应编辑或删除操作。

### 8.5 验收标准

- 划线重启后仍显示。
- 笔记可以回跳原文。
- 删除书籍时相关笔记处理有确认。

## 9. 全局搜索

优先级：P1

### 9.1 搜索范围

- 书名。
- 作者。
- 分类。
- 标签。
- EPUB 正文。
- PDF 文本层。
- 书签备注。
- 笔记。
- AI 问答。

### 9.2 搜索入口

- 底部导航“搜索”。
- 桌面顶部全局搜索框。
- 快捷键 `Ctrl+Shift+F`。

### 9.3 结果类型

- 书籍。
- 正文片段。
- 书签。
- 笔记。
- AI 回答。

### 9.4 操作

- 打开结果。
- 复制片段。
- 保存片段为笔记。
- 对片段提问。
- 过滤结果类型。

### 9.5 验收标准

- 搜索正文能返回匹配片段。
- 搜索笔记能返回笔记。
- 点击结果能跳转。
- 索引未完成时有明确状态。

## 10. AI 问答

优先级：P1

### 10.1 功能说明

AI 问答用于解释、翻译、总结或扩展用户选中的文本。

### 10.2 入口

- 选中文本浮动菜单。
- 阅读器 AI 面板。
- 搜索结果操作。
- 笔记详情页。

### 10.3 快捷动作

- 解释。
- 翻译。
- 总结。
- 提取要点。
- 生成问题。
- 用更简单的话说明。
- 自定义提问。

### 10.4 Provider 设置

字段：

- Provider 名称。
- Base URL。
- API Key。
- Model。
- Temperature。
- Max tokens。
- 是否流式输出。
- 默认系统提示词。

### 10.5 AI 请求状态

| 状态 | 表现 |
| --- | --- |
| 未配置 | 引导到设置 |
| 准备发送 | 显示上下文范围 |
| 发送中 | 流式输出 |
| 已完成 | 显示复制、保存、重试 |
| 失败 | 显示错误和重试 |
| 已取消 | 保留已生成部分，由用户决定是否保存 |

### 10.6 验收标准

- 未配置 API 时不会崩溃。
- 请求可取消。
- 回答可保存为笔记。
- 保存后的 AI 回答可搜索。

## 11. 设置

优先级：P0/P1

### 11.1 设置分组

- 阅读。
- 外观。
- 文件与存储。
- AI。
- 隐私。
- 导出与备份。
- 关于。

### 11.2 阅读设置

- 默认字号。
- 默认字体。
- 默认行高。
- 默认阅读模式。
- 打开书籍恢复进度。
- 阅读器内设置面板提供实时样张预览，并区分 EPUB 排版、PDF 缩放、外观和高级项。

### 11.3 外观设置

- 应用主题：
  - 跟随系统。
  - 亮色。
  - 暗色。
- 阅读主题：
  - 白昼。
  - 纸张。
  - 夜间。
  - 护眼。
  - 高对比。

### 11.4 文件与存储

- 查看书库目录。
- 清理缓存。
- 重建全部索引。

### 11.5 隐私

- 启用 AI。
- 每次请求前确认上下文（默认关闭；上下文始终列在侧栏，见 `03-interaction-spec.md` §13.2）。
- 清空 AI 历史。
- 删除所有本地数据。

### 11.6 验收标准

- 设置变更立即保存。
- 阅读设置能影响新打开的书。
- 敏感设置不会写入普通日志。

## 12. 导出与备份

优先级：P2

### 12.1 导出

支持：

- 导出单本书笔记为 Markdown。
- 导出全部笔记为 Markdown。
- 导出 Notebook 为 Markdown。
- 导出标注为 JSON。
- 导出书签为 CSV。
- 导出 AI 问答为 Markdown。

### 12.2 备份

支持：

- 导出数据库备份。
- 导出书库元数据。
- 恢复数据库备份，后续。

### 12.3 验收标准

- Markdown 中包含书名、位置、原文、笔记内容。
- 导出文件路径由用户选择。
- 导出失败有明确原因。
