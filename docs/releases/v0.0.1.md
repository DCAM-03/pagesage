# PageSage v0.0.1 Beta

PageSage 的首个公开 Beta：本地优先的 EPUB、PDF、Markdown 阅读器，
把阅读、批注、笔记、全文搜索和 AI 辅助整理放在同一个工作台。

这是测试版，欢迎通过 Issue 反馈问题。建议升级前备份已有资料。

## 包含什么

- EPUB、PDF 与 Markdown 阅读、目录导航和阅读进度恢复。
- Markdown 文件夹按原路径只读打开，文件树与单文件大纲分离。
- 划线、批注、书签和关联原文位置的笔记。
- 中文全文搜索与原文定位。
- 自行配置模型服务的 AI 阅读助手与来源引用。
- 平台本地 OCR，支持当前页、指定范围和整本任务。
- 阅读主题、排版设置、备份恢复和导出。
- Apache-2.0 项目许可、内置字体与第三方组件许可说明。

## 下载与安装

附件中的应用版本为 `0.0.1+2`；`+2` 是构建号，Git 标签为 `v0.0.1`。

| 平台 | 文件 | 使用方式 |
| --- | --- | --- |
| Linux x86_64 | `pagesage-0.0.1+2-linux-x86_64.tar.gz` | 解压后运行 `./run-pagesage`，或执行 `bash install.sh` 安装到当前用户目录 |
| Windows x86_64 | `pagesage-0.0.1+2-windows-x86_64.zip` | 完整解压后运行 `pagesage.exe`，保留 DLL 和 `data/` |
| Android | `pagesage-0.0.1+2-android.apk` | 用于设备安装；签名不一致时先确认备份，不要直接卸载唯一的数据副本 |
| Android 分发渠道 | `pagesage-0.0.1+2-android.aab` | 用于支持 App Bundle 的分发渠道，不能直接安装 |

每个安装包附有 `.sha256` 文件。请下载对应校验和，在同一目录校验后使用。
Linux 包由 Ubuntu 22.04 构建；其他发行版需满足 GTK 3、libsecret 与 C++ 运行库要求。
Windows 需要 Visual C++ 2015–2022 x64 Runtime，当前 ZIP 未做 Authenticode 签名。

Linux 可参考：

```bash
sha256sum -c pagesage-0.0.1+2-linux-x86_64.tar.gz.sha256
tar -xzf pagesage-0.0.1+2-linux-x86_64.tar.gz
cd pagesage-0.0.1+2-linux-x86_64
./run-pagesage
```

## 已知边界

- 这是早期 Beta，自动测试和构建通过不代表所有设备和窗口交互都已验收。
- Linux OCR 需额外安装 Tesseract 与所需语言数据；缺少 OCR 不影响基础阅读。
- 扫描 PDF、公式、矩阵和复杂排版的 OCR 结果需要人工核对。
- 公式、Mermaid 与内联 HTML 只覆盖已实现的语法，部分内容会显示源码。
- AI 回答及来源需要核对；模型服务的费用和数据处理受所选服务条款约束。
- 备份包含数据库与封面，不包含全部原书文件或 API key；Markdown 文件夹需自行保留原目录。
- iOS、macOS 和 Web 不在本次分发范围。
