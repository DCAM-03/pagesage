# 大型 EPUB 章节跳转性能修复

日期：2026-11-16

## 问题与范围

- 用户反馈《老舍全集》打开后，目录章节跳转明显卡顿。
- 只读核对本机样本：约 46.8 MiB、2168 个 HTML 条目，当前阅读模式为连续滚动。
- 检查连续列表远距离定位、实际可见位置回报，以及分页章节缓存的生命周期。
- 不修改用户书籍、阅读数据库或应用设置；不扩展个人知识库功能。

## 实施与验证计划

1. 用不含私人正文的合成大书复现跨章节跳转，记录修复前定位与耗时。
2. 让连续阅读直接构建目标附近的内容，避免按整本书滚动距离估算并反复修正。
3. 保持章节前后连续滚动、段落定位、搜索与批注跳转，以及位置事件的正确性。
4. 核对分页缓存仅在文档或排版几何变化时失效。
5. 执行受影响的 EPUB/Markdown/阅读器回归、静态分析和静默 Linux 安装。

### 验证入口

- `test/renderers/epub/epub_chapter_navigation_test.dart`：远距离目录跳转、段落定位、
  快速连续跳转、当前位置事件、目标前后滚动。
- 真实 EPUB 可选验证通过 `EPUB_NAVIGATION_SAMPLE` 显式传入路径，只输出章节数、
  正文字数与耗时，不复制正文、不把书籍纳入仓库。
- 既有 `test/renderers/epub/`、`test/renderers/markdown/` 与阅读器受影响用例。
- 证据目录：`.local-data/validation/epub-navigation-2026-11-16/`。

## 当前发现

- 连续阅读把整本书切片放入一个普通惰性列表，但跳转依赖估计的总滚动高度，
  最多反复修正 12 次；章节长度和布局不均匀时，估算既昂贵又不能保证命中。
- 每次切片构建会重新转换该章节全部 block。
- 分页章节切换会调用完整缓存失效，抵消已有的最近章节缓存与邻章预取。

## 执行结果

### 修复

- 连续阅读改为以目标切片为锚点，在锚点前后分别惰性构建内容。跨章不再通过总滚动
  高度猜测位置，也不逐帧修正远距离滚动；目标前后的章节仍可连续滚动。
- 根据实际可见切片计算章节与位置事件，不把像素高度比例当作原文字数比例。
- 跨章定位直接完成；已有普通翻页、滚轮和键盘阅读操作继续使用各自的交互。
- 连续阅读缓存最近 10 章的 block 转换结果，切片构建不再重复转换整章。
- 跳转回调核对请求代际、文档身份、阅读模式与组件生命周期，避免旧回调覆盖新目标。
- 换字号与阅读模式时捕获当前可见位置；切换文件时清理锚点，并等待新文档完成，
  不使用 FutureBuilder 暂留的旧文档数据构建新文件。
- 分页首次只测量请求的章节；普通切章保留最近章节分页结果，字号、几何或文档变化
  时才失效。主题变化不清空测量结果。
- 保留连续切片的全局语义索引、正文列宽、选区与既有定位事件契约。无依赖或数据库变更。

### 同样本性能证据

样本为用户本机 EPUB，只读加载，2168 个 spine 条目、7,540,056 个正文字符。
以下均为 Flutter 离屏 widget 测试的实际墙钟时间，计时包括更新跳转目标与
`pumpAndSettle`，不含首次 EPUB 解压解析；不能解释为真实桌面 release 的端到端耗时。

| 条件 | 修复前 | 修复后 |
| --- | --- | --- |
| 相同真实中文字体，跳往索引 309 | 25065 ms，目标正确 | 87 ms，目标正确 |
| 同一中文字体，后续跳往 1084 / 2164 / 309 | 未完成 | 52 / 77 / 39 ms，目标均正确 |

- 更早的默认测试字体诊断中，旧版跳往索引 309 耗时 8244 ms，位置回报为 212，
  断言失败；合成大书的四个初始导航用例也全部失败，证实除耗时外还存在定位缺陷。
- 中文字体基线使用 `da3f8ce` 的独立源码副本和同一测试、字体加载器、800×600
  viewport、阅读设置与文件。第一次跳转已耗时约 25 秒，进入第二次后测试进程 RSS
  观察值约 2.6 GiB，因继续长测收益有限而主动中断；不把该基线整轮视为通过，
  也不把测试进程 RSS 当作实际应用整体内存。
- 修复后四个真实文件跳转全部通过。首次文件解析仍约 3.4 秒，本次未调整解析器，
  不声称消除了首次加载成本。
- 日志：`baseline-synthetic.log`、`baseline-real.log`、`baseline-real-cjk.log`、
  `real-final-cjk.log`。独立基线源码副本移至临时目录，未混入工作树或验证扫描。
