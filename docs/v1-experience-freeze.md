# PageSage v1.0 体验冻结清单

版本：0.1  
日期：2026-07-17  
状态：产品范围冻结草案（用于砍功能、定优先级、人工验收）  
对照：`00-overview.md`、`01-product-requirements.md`、`07-roadmap.md`、`implementation-status.md`、`m4-release-checklist.md`、`tasks/pdf-ocr-optional.md`

---

## 0. 为什么要冻结

当前主路径（导入 → 阅读 → 标注 → 搜索 → AI → 导出）在功能上已基本闭环，但 **PDF 真实感、标注可信度、chrome 重复** 仍会摧毁「本地知识工具」的信任。

本清单的目标不是继续加功能，而是：

1. 明确 **v1.0 必须过关** 的体验契约。  
2. 明确 **明确延后** 的功能，避免在 OCR/像素级细节上无限消耗。  
3. 给出可勾选的验收标准，方便按清单砍范围。

### 北极星（v1.0 唯一）

> 用户打开自己的 EPUB/文本 PDF，连续阅读 30 分钟：不觉得烦、不觉得慌、不觉得假；划线与笔记在重启后仍在，且能搜到、能导出。

扫描 PDF / OCR 是增强项，**不得阻塞**上述北极星。

## 1. 产品一句话（对外）

**PageSage：本地书库里的深度阅读与知识沉淀。AI 只在你点的时候出现，且你永远看得见它读了哪一段。**

不要对外说成：

- 「又一个带 AI 的 PDF 阅读器」  
- 「全自动理解整本书」  
- 「扫描件 OCR 已完美」

## 2. 冻结原则

| 原则 | 含义 |
| --- | --- |
| 先不可恨，再不可替代 | 稳定、可预期优先于新能力 |
| 一套 chrome | 用户只应看到 Flutter 阅读壳，不看到 WebView 内部第二套工具栏 |
| 标注 = 信任功能 | 几何不可信时宁可降级提示，不要假装精确 |
| AI 克制 | 用户触发、上下文可见、可取消；不做模型超市 |
| 本地数据可带走 | 备份/导出是一等公民 |
| 范围冻结 | 未列入「必须做」的项，默认不做进 v1.0 |

### 冻结期禁止事项

除非修复 P0 崩溃/数据丢失，否则冻结期内 **不要**：

- 新开大功能（云同步、账号、多窗口、插件市场、在线书店等）  
- 继续开放式微调 OCR 选区/永久标注像素，而无书面验收契约  
- 引入大型依赖「顺手优化 UI」  
- 扩大 OCR 到整书自动任务 / 进 FTS（除非单独评审改路线图）

## 3. 体验契约（按场景）

### 3.1 书库与导入

| 契约 | 验收 |
| --- | --- |
| 导入 EPUB/PDF 进入统一书库 | 选择/拖拽后书出现在书库；hash 去重不产生重复本 |
| 索引不卡死 UI | 大 PDF 索引时界面可操作；失败可重试且不复制出第二本书 |
| 扫描 PDF 索引语义清晰 | `indexingStatus=no_text` 显示「无可索引正文」，不是失败红错 |

### 3.2 阅读（EPUB / 文本 PDF）

| 契约 | 验收 |
| --- | --- |
| 打开即读 | 3 秒内可见正文（本地文件、常规体量）；无空白只剩工具栏 |
| 进度可恢复 | 关闭重开回到上次位置（允许微小偏差，不可跳章/跳错页） |
| 仅一套操作栏 | **桌面与移动均不显示** PDF WebView 内 HTML `#toolbar`；缩放/模式/跳页走 Flutter |
| 主题与字号 | 切换后立即生效且持久化；不导致正文空白 |
| 目录/页跳 | EPUB TOC、PDF 大纲或页码可跳转 |

### 3.3 标注与笔记（信任核心）

#### 文本 PDF / EPUB（精确路径）

| 契约 | 验收 |
| --- | --- |
| 临时选中 | 选中范围与手指/鼠标一致；不整页乱跳 |
| 永久高亮 | **只覆盖选中文本**；不整行灌满；不明显盖住下一行 |
| 颜色 | 保留黄/蓝/绿/红/紫等标注色，不与临时选中强行同色 |
| 重启仍在 | 杀进程重开后标注仍在对应位置附近（文本 PDF 应基本重合） |
| 笔记 | 可从选区写笔记；Notebook 可见；可搜索 |

#### 扫描 PDF（降级契约 — v1.0 允许）

| 契约 | 验收 |
| --- | --- |
| 可读 | 无文本层仍可翻页阅读 |
| OCR 可选 | 用户主动「识别可见页」；失败不挡阅读 |
| 标注诚实 | 若几何为近似：UI 不承诺「印刷级贴字」；可接受行级近似，但 **禁止** 明显跨到未选中行且无说明 |
| 不可用时 | 明确提示「无文本层 / 需先识别」，而不是静默无操作 |

> **冻结决策：**  
> - **OCR 必做**（识别可见页、本地缓存、可划词），不是可砍功能。  
> - **永久标注硬约束：不得盖住未选中的下一行**（文本 PDF 与 OCR 页一律适用）。  
> - 扫描页允许「近似贴字」，但跨行误盖 = 缺陷，必须修，不是接受项。  
> - 整书 OCR / OCR 进 FTS / 印刷级完美仍 post-v1.0；**可见页 OCR + 不跨行标注** 属于 v1.0。

### 3.4 搜索

| 契约 | 验收 |
| --- | --- |
| 书名/作者可搜 | 导入后可搜到 |
| 正文可搜 | 有文本层 EPUB/PDF 可搜；`no_text` 不误报索引中 |
| 笔记/AI 可搜 | 用户写过的内容能搜到 |
| 跳转 | 点结果进入书中对应位置（扫描无层时跳到页即可） |

### 3.5 AI

| 契约 | 验收 |
| --- | --- |
| 仅用户触发 | 无自动整书上传 |
| 上下文可见 | 发送前可见将发送的文本范围/描述 |
| 可取消 | 生成中可取消；已生成部分可保留或丢弃由用户决定 |
| 可沉淀 | 回答可保存为笔记并被搜索 |
| 未配置 | 明确引导去设置，不崩溃 |

### 3.6 数据与退出

| 契约 | 验收 |
| --- | --- |
| 备份/恢复 | 见 `m4-release-checklist.md` |
| 导出 | 笔记/标注/书签/AI 至少一种实用导出路径可用 |
| 删书 | 删书库记录不删用户原始文件路径；OCR/索引等本地衍生数据应清理 |

## 4. 必须做 / 明确延后

### 4.1 v1.0 必须做（P0 / P1）

| ID | 项 | 优先级 | 完成定义 |
| --- | --- | --- | --- |
| F-01 | **单 chrome**：隐藏 PDF HTML `#toolbar`（全端） | P0 | 桌面打开 PDF 只见 Flutter 工具栏/状态栏；缩放与显示模式入口仍可达 | **已实现 2026-07-17**：`viewer.css` 全局隐藏 `#toolbar`；`viewer.html` `hidden` + cache bust |
| F-02 | **永久标注不盖下一行**（含 OCR 页） | P0 | 新标注只盖选中宽度；高度短条贴字带；**禁止**压到未选中下一行；重启可恢复 | **加强 2026-07-17**：顶对齐短条 + 像素硬顶 8px + 相对下一 OCR 行硬截断 |
| F-03 | **扫描 PDF 标注诚实 + OCR 必做** | P0 | OCR 入口/缓存保留；UI 标明近似；仍须满足 F-02 不跨行 | **S-B 文案已落地**；OCR 不砍；跨行按 F-02 修 |
| F-04 | **无空白阅读器** | P0 | EPUB/PDF 打开后正文区域可见；回归用例纳入手测 | 回归保持；手测 |
| F-05 | **导入/索引不卡死、不双书** | P0 | 大 PDF 索引可后台；失败重试不复制书 | 前期已落地；手测 |
| F-06 | **OCR 入口可预期** | P1 | 无原生文本层始终可找「识别可见页」；识别后入口不消失 | **已实现 2026-07-17**：`nativeTextLayer` 与 `ocrTextLayer` 分报；入口看 native |
| F-07 | **AI 上下文展示** | P1 | 桌面侧栏/移动面板发送前范围清晰 |
| F-08 | **备份恢复手测通过** | P1 | `m4-release-checklist.md` 全勾 |
| F-09 | **Windows 核心闭环手测** | P1 | 导入→读→标→搜→AI→导出 全绿 |
| F-10 | **Android 至少一条主路径手测** | P1 | 导入+打开+进度恢复（有设备时） |

### 4.2 v1.0 明确延后（不要做）

| 项 | 原因 |
| --- | --- |
| 整书/选页 OCR 任务队列 + 任务中心 | 范围膨胀；非北极星 |
| OCR 进 FTS 全局搜索 | 依赖任务队列与质量策略 |
| ONNX / 自研 OCR 引擎 | 体积与维护成本 |
| 扫描 PDF 印刷级 bbox 完美贴字 | 高难长尾；冻结为 post-v1.0 |
| MOBI/AZW、Calibre 转换 | 路线图已延后 |
| 云同步、账号、协作、在线书店 | 产品边界 |
| DRM 绕过 | 合规禁止 |
| iOS / macOS / Linux 首发 | 非首发平台 |
| 大改 AI Provider 矩阵 / 本地大模型运行时 | 非 v1.0 差异化重点 |

### 4.3 可做可不做（有余力）

- 中文 FTS 分词增强  
- 更完整的 Markdown 渲染  
- 商店签名/安装器打磨  
- 辅助功能逐项清单勾选  
- 桌面快捷键补全文档中的遗漏项

## 5. 扫描 PDF / OCR 冻结策略（写死）

权威任务文档：`docs/tasks/pdf-ocr-optional.md`。

### v1.0 采用策略（推荐默认）

**策略 S-B：可读 + 可选 OCR + 标注诚实降级**

| 能力 | v1.0 |
| --- | --- |
| 打开/翻页/进度 | 必须 |
| 「识别可见页」本地 OCR | 必须可用（Android/Windows） |
| OCR 结果会话+磁盘缓存 | 已有则保持；删书清理 |
| 识别后划词 | 尽力而为；失败可提示 |
| 永久高亮在扫描页 | **行级近似可接受**；若仍跨行严重 → 改为「仅保存笔记/摘录，不画跨行色块」 |
| 整书 OCR / OCR 搜索 | 延后 |

### 退出条件（何时允许再打磨扫描高亮）

同时满足才重新开放 OCR 几何迭代：

1. F-01 单 chrome 已完成。  
2. 文本 PDF/EPUB 永久标注手测全绿。  
3. 有固定样本集（至少 3 本扫描 PDF）与截图基线。  
4. 每次改动只改一条变量（高度 / 数据源 / 绘制），并记录前后截图。

## 6. 手测验收清单（v1.0 体验）

在 `m4-release-checklist.md` 之外，增加以下 **体验向** 勾选。样本可用 `dart run tool/generate_manual_samples.dart` 与真实用户书。

### 6.1 Windows 桌面

- [ ] 打开文本 PDF：仅一套顶部/工具 chrome，**无** WebView 内第二套「上一页/缩放」条  
- [ ] 打开 EPUB：正文可见，目录可跳，进度可恢复  
- [ ] 文本 PDF：选中若干字 → 高亮 → **仅这些字** 有色，不整行、不严重盖下一行  
- [ ] 重启后高亮仍在  
- [ ] 扫描 PDF：可阅读；「识别可见页」可找到；识别失败不白屏  
- [ ] 扫描 PDF 标注行为符合 §5 写死策略  
- [ ] 全局搜索：书名 + 一条笔记/AI 回答可命中并跳转  
- [ ] AI：划词 → 见上下文 → 发送 → 取消/完成 → 存笔记  
- [ ] 备份/恢复按 M4 清单  
- [ ] 连续阅读 30 分钟：无崩溃、无空白页、无明显卡死  

### 6.2 Android（有设备时）

- [ ] 导入 + 打开 + 进度恢复  
- [ ] 工具栏沉浸：阅读中不永久遮挡正文  
- [ ] 文本选择与返回手势不冲突到无法阅读  

### 6.3 回归红线（任一失败则不可称 v1.0）

- [ ] 打开书只见工具栏、正文空白  
- [ ] 导入/重试产生重复书  
- [ ] 索引导致 UI 长时间完全卡死  
- [ ] 标注导致崩溃  
- [ ] AI 或导入默认上传整书

## 10. 一句话结论

**v1.0 = 可靠的本地阅读与沉淀闭环，而不是完美的扫描 OCR 演示。**  
先让用户敢把常用书放进来；扫描件与像素级高亮，放到信任建立之后再打。
