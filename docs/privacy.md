# PageSage 隐私说明

PageSage 是本地优先阅读器。默认情况下，书籍副本、阅读进度、书签、标注、笔记、全文索引、AI 对话记录和应用设置都保存在本机。

## 本地数据

- 导入普通 EPUB/PDF/Markdown 文件时，PageSage 会复制到应用书库目录。
- Markdown 文件夹按原路径只读访问，不复制、不写入源文件夹；移除书库条目不删除原目录。
- 删除 PageSage 内的书籍不会删除用户原始路径中的文件。
- 删除所有本地数据会清空应用书库、进度、书签、标注、笔记、AI 记录、搜索索引和普通设置。
- API key 存在系统安全存储中，不写入 SQLite。

## AI 数据

- AI 功能默认不自动上传整本书。
- AI 面板会展示将发送的选中文本或上下文范围。
- 发送的内容由配置的模型服务处理，其数据保留与使用还受该服务政策约束。
- 用户可以关闭联网 AI，也可以清空 AI 历史。
- 清空 AI 历史不会删除已经另存为普通笔记的内容。

## 日志与诊断

默认日志不记录 API key、AI 请求正文、选中文本、完整上下文或大段书籍正文。后续如果增加诊断导出，也必须先脱敏并让用户主动导出。

公开反馈前请检查截图、文件名、文件路径、服务地址与日志，不上传私人书籍、
个人数据库或凭证。安全问题按 [SECURITY.md](../SECURITY.md) 私下报告。

## 备份与恢复

备份先在本地生成，再通过保存交互写入用户选择的位置；取消不会当作导出成功。
备份包含数据库与封面，数据库可能包含笔记、摘录、批注和 AI 对话，应按私人资料保管。
备份不是整套书籍文件的打包，也不包含系统安全存储中的 API key；换设备后需要另行迁移
原书文件、重新关联 Markdown 文件夹，并配置必要的凭证。

恢复备份会替换应用数据库和封面，恢复前会创建回滚副本。不要把个人备份放入仓库、
公开 Issue 或构建附件。
