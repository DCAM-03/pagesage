# PageSage 隐私说明

PageSage 是本地优先阅读器。默认情况下，书籍副本、阅读进度、书签、标注、笔记、全文索引、AI 对话记录和应用设置都保存在本机。

## 本地数据

- 导入书籍时，PageSage 会把 EPUB/PDF 复制到应用书库目录。
- 删除 PageSage 内的书籍不会删除用户原始路径中的文件。
- 删除所有本地数据会清空应用书库、进度、书签、标注、笔记、AI 记录、搜索索引和普通设置。
- API key 存在系统安全存储中，不写入 SQLite。

## AI 数据

- AI 功能默认不自动上传整本书。
- AI 面板会展示将发送的选中文本或上下文范围。
- 用户可以关闭联网 AI，也可以清空 AI 历史。
- 清空 AI 历史不会删除已经另存为普通笔记的内容。

## 日志与诊断

默认日志不记录 API key、AI 请求正文、选中文本、完整上下文或大段书籍正文。后续如果增加诊断导出，也必须先脱敏并让用户主动导出。

## 备份与恢复

数据库备份会导出到本地 `exports` 目录，文件名形如 `pagesage-backup-YYYYMMDD.zip`。恢复备份会覆盖当前应用数据库，恢复前会创建回滚副本。
