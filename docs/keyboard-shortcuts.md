# PageSage 快捷键

平台：Windows / 桌面  
日期：2026-07-16  

| 快捷键 | 作用 | 位置 |
| --- | --- | --- |
| `Ctrl+O` | 导入书籍（进入书库并发起导入） | 主壳、阅读器 |
| `Ctrl+Shift+F` | 打开全局搜索 | 主壳、阅读器 |
| `Ctrl+F` | 本书内搜索 | 阅读器 |
| `Ctrl+B` | 添加/取消当前位置书签 | 阅读器 |
| `Ctrl+G` | 跳转页码（PDF） | 阅读器 |
| `Ctrl+=` / `Ctrl++` | 放大（PDF 缩放 / EPUB 字号） | 阅读器 |
| `Ctrl+-` | 缩小 | 阅读器 |
| `Ctrl+0` | 重置比例 | 阅读器 |
| `Esc` | 关闭浮层/侧栏/选择菜单 | 阅读器 |
| `Enter` / `Shift+Enter` | 本书搜索下一/上一结果 | 书内搜索面板 |
| 方向键 / 空格 | 翻页或滚动 | EPUB 渲染器（分页/连续） |

## 手测建议

1. 在书库：`Ctrl+O` 打开文件选择。  
2. 打开 EPUB：`Ctrl+F` 搜索，`Enter` 跳转，`Ctrl+B` 书签。  
3. 打开 PDF：`Ctrl+G` 跳页，`Ctrl+=/-` 缩放。  
4. `Esc` 依次关闭搜索面板、目录、选择菜单。
