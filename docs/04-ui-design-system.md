# PageSage UI 与视觉规范

版本：0.2  
日期：2026-07-03  
状态：详细 UI 规范，现代化设计系统迁移中  

## 0. 现代化迁移说明

本文件是 PageSage 早期 UI 与视觉规范，仍可作为历史背景和阅读主题参考。后续 UI/UX 现代化改造应优先使用：

- `docs/08-ui-ux-redesign-plan.md`
- `docs/09-design-system.md`
- `docs/tasks/ui-ux-modernization.md`
- `docs/testing-ui-ux-checklist.md`

若本文件与新版设计系统冲突：

- 颜色、排版、间距、圆角、组件状态以 `docs/09-design-system.md` 为准。
- 页面布局、导航、阅读器、搜索、Notebook 和 AI 面板以 `docs/08-ui-ux-redesign-plan.md` 为准。
- 本地优先、AI 主动触发和功能边界仍以产品需求和 AGENTS 指令为准。

现代化后的视觉目标：

- 减少默认 Flutter 控件拼装感。
- 建立统一 token，而不是在页面中散写颜色、字号和 padding。
- 桌面端体现现代生产力工具质感。
- 移动端保持沉浸阅读和触控友好。
- AI 视觉低噪声、透明、克制。

## 1. 设计目标

PageSage 的界面应该像一套长期使用的阅读工具，而不是营销页或一次性演示。视觉应克制、清晰、稳定，优先服务阅读、检索和沉淀。

关键词：

- 安静。
- 高可读。
- 少干扰。
- 工具感。
- 本地知识库。
- 轻量智能。

## 2. 设计原则

1. 内容优先  
   阅读正文、搜索结果、笔记内容永远是页面核心。

2. 操作明确  
   导入、搜索、阅读、标注、AI 等动作必须通过常见控件表达，不用隐晦图形。

3. 密度适中  
   桌面端允许更高信息密度，移动端保持触控空间。

4. 视觉不过度装饰  
   不使用大面积渐变、装饰性圆球、复杂背景图。

5. 主题不影响阅读  
   阅读主题可以个性化，但正文对比度必须足够。

## 4. 字体

### 4.1 UI 字体

Flutter 默认使用系统字体。

建议：

- Android：系统默认 sans。
- Windows：Segoe UI + Microsoft YaHei UI。
- 中文内容：系统中文字体。
- 英文内容：系统 UI 字体。

### 4.2 阅读字体

默认选项：

- 系统默认。
- 无衬线。
- 衬线。
- 等宽。

后续：

- 导入自定义字体。

### 4.3 字号

UI 字号：

| Token | Size | 用途 |
| --- | --- | --- |
| `text.xs` | 12 | 辅助信息 |
| `text.sm` | 14 | 次级文本 |
| `text.md` | 16 | 正文 UI |
| `text.lg` | 18 | 小标题 |
| `text.xl` | 22 | 页面标题 |
| `text.2xl` | 28 | 大标题，少用 |

阅读字号：

- 默认：18。
- 范围：14 到 32。
- 步进：1。

规则：

- 不用 viewport width 动态缩放字号。
- 卡片和按钮内文字不能溢出。
- 长标题最多两行，超出省略。

- 不做大圆角卡片嵌套。

- 右侧面板最小宽度：300。
- 右侧面板最大宽度：520。
- 内容最大宽度：
  - 设置页：960。
  - 笔记详情：880。
  - 阅读器正文由阅读设置控制。

### 5.4 移动布局尺寸

- 顶部工具栏高度：56。
- 底部导航高度：64。
- 底部抽屉最小高度：240。

- 列表项最小触控高度：48。
- 图标按钮触控区域：48 x 48。

## 6. 图标

## 7. 组件规范

### 7.1 按钮

类型：

- Primary button：主要操作，如导入。
- Secondary button：次要操作，如扫描文件夹。
- Text button：低强调操作。
- Icon button：工具栏操作。
- Danger button：删除和清空。

规则：

- 同一个区域最多一个 Primary button。
- Danger button 不作为默认焦点。
- Icon button 必须有语义标签。

### 7.2 输入框

搜索框：

- 左侧搜索图标。
- 右侧清空按钮。
- 支持 placeholder。
- 聚焦后显示快捷键提示，桌面端。

文本输入：

- 多行笔记支持 Markdown。
- AI 输入框支持换行，Enter 发送可配置，默认 Ctrl+Enter 发送。

### 7.3 菜单

菜单项结构：

- 图标。
- 文本。
- 快捷键，桌面端。
- 危险操作分组到底部。

规则：

- 菜单项高度不小于 40。
- 长菜单使用分组分割线。
- 禁用项显示原因或 tooltip。

### 7.4 标签

标签样式：

- 小圆角胶囊。
- 左侧可有颜色点。
- 文本最多一行。

用途：

- 书籍标签。
- 搜索过滤。
- 结果类型。

### 7.5 卡片

书籍卡片：

- 固定封面比例 2:3。
- 标题最多两行。
- 作者一行。
- 进度条高度 3。

搜索结果卡片：

- 类型标签。
- 来源书名。
- 位置。
- 片段。
- 操作按钮。

笔记卡片：

- 书名。
- 原文摘录。
- 笔记正文摘要。
- 更新时间。

规则：

- 卡片用于重复项目。
- 页面区块不用卡片套卡片。

## 8. 页面规范

### 8.1 书库页

移动端：

- 顶部标题和搜索入口。
- 书籍网格 2 到 3 列。
- 浮动或顶部导入按钮。

桌面端：

- 左侧分类。
- 顶部工具栏。
- 中间网格或列表。
- 右侧详情。

### 8.2 搜索页

移动端：

- 搜索框固定顶部。
- 筛选横向滚动。
- 结果列表。

桌面端：

- 搜索框在顶部。
- 左侧或顶部过滤。
- 中间结果。
- 右侧预览，P2。

### 8.3 笔记页

移动端：

- 筛选 chips。
- 笔记列表。
- 点击进入详情。

桌面端：

- 左侧笔记列表。
- 右侧详情编辑。

### 8.4 设置页

移动端：

- 分组列表进入二级页面。

桌面端：

- 左侧分组。
- 右侧设置项。

## 9. 阅读器 UI

### 9.1 EPUB 正文

默认样式：

- 字号：18。
- 行高：1.7。
- 段落间距：0.8em。
- 最大行宽：桌面约 720 到 860。
- 移动端左右边距：20。

规则：

- 正文不能贴边。
- 标题层级保持 EPUB 原样，但可通过主题统一颜色。
- 代码块使用等宽字体，背景弱化。

### 9.2 PDF 正文

规则：

- PDF 页面居中。
- 外侧背景使用阅读主题背景。
- 页面之间间距固定。
- 缩放控件不遮挡页面内容。

### 9.3 阅读器工具栏

工具栏背景：

- 亮色：半透明白或 surface。
- 暗色：半透明深灰。

规则：

- 工具栏不能持续遮挡正文。
- 移动端阅读中默认隐藏。
- 桌面端可固定显示。

### 9.4 AI 面板

结构：

- 选中文本摘要。
- 快捷动作。
- 上下文范围。
- 输入框。
- 回答区域。
- 操作区。

视觉：

- 不用强烈科技风。
- AI 相关强调色使用 `color.accent` 或淡紫标签。
- 回答正文按普通阅读文本排版。

## 10. 响应式规则

断点：

| 名称 | 宽度 |
| --- | --- |
| compact | < 600 |
| medium | 600 - 1023 |
| expanded | >= 1024 |

compact：

- 底部导航。
- 单列页面。
- 阅读器全屏。
- 面板使用底部抽屉。

medium：

- 平板可使用双栏。
- 阅读器可显示侧边目录抽屉。

expanded：

- 左侧导航。
- 中间主内容。
- 右侧上下文面板。

## 11. 可访问性

要求：

- 所有图标按钮有语义标签。
- 文本对比度满足 WCAG AA。
- 支持高对比主题。
- 支持键盘导航。
- 支持屏幕阅读器读出主要按钮。
- 不仅依靠颜色表达状态。
- 动画应可减少。

键盘焦点：

- 焦点样式清晰。
- Tab 顺序符合视觉顺序。
- 弹窗打开后焦点限制在弹窗内。

## 12. 动效

原则：

- 轻量。
- 快。
- 不影响阅读。

建议：

- 面板展开：150 到 200ms。
- snackbar：进入 150ms，停留 3s。
- 书籍卡片 hover：轻微背景变化，不位移。
- 阅读翻页动画首版可关闭或极简。

## 13. 图片资源使用

图片资源仅用于：

- App 图标。
- 空状态插画。
- 默认封面。
- 商店宣传图。
- 教程或帮助图片，后续。

不用于：

- 工具栏图标。
- 菜单图标。
- 普通按钮图标。
