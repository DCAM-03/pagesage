# 阅读器界面与瞬时提示

用于阅读器工具条、SnackBar、浮动面板和自动收起交互。复用现有主题、控件和
`lib/features/reader/presentation/reader_chrome.dart`。

具体交互和时长以 [交互规范](../../../../docs/03-interaction-spec.md) 为准，
尺寸与视觉以 [设计规范](../../../../docs/04-ui-design-system.md) 和现有主题为准。
本参考保留工程注意事项，不复制产品参数或把某次修复固化为所有界面的实现方式。

## 工具条与自动收起

- 区分自动收起、用户主动收起和唤回，逐条核对实际入口；提供可由键盘操作的唤回入口。
- 隐藏控件不能留下不可见的命中区或焦点，读屏应能访问替代入口。按实际结构选择移除
  子树、可见性组件或 `IgnorePointer` / `ExcludeFocus` / `ExcludeSemantics`；仅改透明度
  不等于完成隐藏。
- 自动隐藏要考虑悬浮、键盘焦点和正在进行的操作。计时器由实际拥有者取消和释放，
  不在每次 build 或 hover 中堆积任务，退出阅读器后不得继续更新界面。

## SnackBar 与模式提示

- 核对项目实际 Flutter 版本中 `action`、`persist`、`duration` 及无障碍设置的组合行为。
  要求自动消失的提示须显式表达持续策略；支持 `persist` 的版本可用 `persist: false`，
  不能只设置时长就假定会超时。
- 根据消息关系选择替换或排队，连续触发同类操作不应积压过时提示；不无条件清除无关
  错误或重要结果。异步完成后核对界面存活与请求归属再展示。
- 短时操作结果、持续编辑模式和后台任务进度分别使用相应的现有组件，不强制所有状态
  使用 banner。提供实际支持的退出或取消入口，不暗示任务已取消而后台仍在运行。

## 验证

- 按改动选择行为测试：推进时间验证带操作提示确实消失、工具条确实收起；触发实际入口
  验证悬浮、主动收起、唤回或键盘操作。属性和回调断言只能作为补充。
- 布局需要时补离屏截图；验证层次、静默执行和本地安装沿用 `validation-harness`。
